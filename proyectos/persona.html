Descripción

La idea de este proyecto surge de una app de android que ya no existe. Solía usarla para buscar información sobre el juego más cómodamente, pero debido a falta de soporte, fue removida de la Google Play Store, así que decidí hacer algo parecido yo mismo.

Este proyecto fue realmente divertido, Persona 5 tiene una de mis direcciones artísticas favoritas. Comencé este proyecto para entender mejor cómo funcionan JavaScript y Css, pues hasta la fecha sólo había trabajado con Vue y Bootstrap. Encontré más divertido programar mi propia lógica que depender de la caja negra que a veces pueden parecer estas librerías, pero entendí bien el valor que tienen, pues hacer este proyecto me tomó mucho más tiempo del que habría necesitado utilizando alguno de estos frameworks.
